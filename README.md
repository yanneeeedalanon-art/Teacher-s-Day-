# 💙 Teachers' Day Letter for Sir Randy Bello

## 📌 Project Description

This project is a creative and interactive **Teachers' Day digital letter** made especially for **Sir Randy Bello**, a Web Development instructor.

The project uses **HTML, CSS, and JavaScript**, all combined into a single `index.html` file.

## ✨ Features

* 💌 Animated opening envelope
* 🎈 Floating animated balloons
* 🩵 Light-blue Teachers' Day theme
* 🌙 Dark Mode and Light Mode switch
* ✨ Smooth transitions and animations
* 👨‍🏫 Personalized letter for Sir Randy Bello
* 📱 Responsive design for desktop and mobile devices
* 💻 HTML, CSS, and JavaScript in one file
* 🔄 Button to close and reopen the letter

## ▶️ How to Run

1. Download or copy the project files.
2. Make sure `index.html` and `README.md` are in the same folder.
3. Open the `index.html` file.
4. The Teachers' Day letter will open in your web browser.
5. Click the envelope to open the letter.
6. Use the **Dark Mode / Light Mode** button to change the theme.

## ✏️ How to Customize

To change the student name, open `index.html` and find:

```html
<div class="signature-name">
    Your Student
</div>
```

Replace `Your Student` with your name.

You can also modify the letter message, colors, animations, and other design elements directly inside `index.html`.
